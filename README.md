# MANGKAT – Driver Monitoring System

MANGKAT is a machine learning-based driver monitoring system designed to detect driver conditions, including fatigue, distraction, and normal driving behavior. The system uses a MobileNet-based model with TensorFlow and TensorFlow Lite to classify driver conditions and provide audio alerts when necessary, aiming to support safer driving.
